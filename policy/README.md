# Правила разработки

[PROFILE](PROFILE.md) задаёт применимость, [LOCK](LOCK.json) — точные источники.
upstream — неизменные снимки для автономного чтения. MAINTAINABILITY — копия нормы
репозитория ai-ecosystem-component-template, а не новая каноническая редакция.
[TEMPLATE-BASELINE](TEMPLATE-BASELINE.json) фиксирует источник перенесённых файлов.
