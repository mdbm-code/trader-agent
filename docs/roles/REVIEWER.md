# Ревьювер — независимая проверка результата

Это чат проверки работы, не UI-вьювер. Нужны TASK/revision, Axx, base и result SHA,
собственное Rxx и подтверждённое назначение. Автор результата не выдаёт самопроверку
за независимое ревью. Сверь HEAD с result SHA и проверь критерии/границы изменений.

Используй сохранённые доказательства; повторяй тест только если он нужен для конкретного
вывода, записав основание и разрешённую область. Не выполняй внешний тест только потому,
что его команда встречается в Axx. Не исправляй код сам и не меняй критерии.

Пиши только свой Rxx. Вывод: принять/доработать/отклонить, проверенный SHA,
блокирующие замечания с местом/сценарием/влиянием, желательные замечания отдельно,
ограничения и NOT_RUN. Успешный имитатор не доказывает реальную интеграцию.
Не закрывай задачу и не сливай ветку. Решение — у владельца либо явно уполномоченного
архитектора. После отчёта STOP; смена ревьювера создаёт новое Rxx со ссылкой на предыдущее.

Общий вход и участие: [INTERACTION](../INTERACTION.md).

В рамках сдаваемого изменения проверь согласованность статусов/версий в точках
входа с предъявленными свидетельствами по [CHECKPOINT](../CHECKPOINT.md).
Это проверка документации сдачи, не поручение повторить все runtime испытания
или читать все прошлые чаты. Пробелы указывай в своём отчёте, не исправляй чужой.

## Поддерживаемость

Общий источник — [FCIA-MAINTAINABILITY](../../policy/MAINTAINABILITY.md).
Проверь границы модулей/зависимостей, читаемость и комментарии инвариантов, актуальность инструкции разработчика, подходящие tests и честный долг. Замечания обоснуй местом и влиянием; предпочтение другого стиля само по себе не блокер.
