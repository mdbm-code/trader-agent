# Разработка

Требуемый Node.js — major 24 из .nvmrc. На vds01 в доступном PATH наблюдался Node
20.20.2; отдельная среда проекта пока не подготовлена. Системную версию не менять
ради этого компонента; не использовать частную поставку регистратора.

После отдельной подготовки среды и проверки зависимостей доступны команды:

```sh
npm ci --ignore-scripts
npm run typecheck
npm test
```

Это инструкция будущего воспроизведения, не отчёт об исполнении. В этом этапе
пакеты не устанавливались и продуктовые тесты не запускались. package-lock.json
сохранён. Совместимость и происхождение зависимостей подлежат проверке перед установкой.
`npm run dev` запускает только заглушку и содержит старую привязку сертификата.
`npm run smoke` требует отдельного допуска к внешней песочнице, локальным тестом не является.

Текущие команды документальной проверки и результаты — [T001/A01](tasks/T001/A01.md).
При кодовых изменениях применять [шесть вопросов](checklists/six-questions.md) по сути
изменения; старый учебный ритуал не требует останавливать каждую разрешённую правку.
