# Текущая архитектурная точка

Основание перехода — [ADR 0002](adr/0002-remote-fcia-documentation.md).

## Фактическая реализация

- src/app/main-worker.ts — заглушка, печатающая одну строку.
- src/shared/errors/ — ошибки, обработчики и маскировка с unit-тестами.
- scripts/smoke.mjs — прежний прямой клиент песочницы T-Invest с внешними эффектами.
- UI, стратегии, бэктест, хранилище котировок и рабочий аналитический API отсутствуют.

## Профиль поддерживаемости

Сохраняются TypeScript strict, kebab-case, небольшие смысловые модули, unit-тесты
рядом с кодом. Внешние данные и API отделять от вычислений; зависимости передавать
явно. Новый код документирует причины и контракты, а не каждую строку.
Будущие расчёты денежных величин требуют явной точности/единиц; Money/Clock из старого
проекта остаются идеей, не уже существующими классами. Пустые слои не создаём.

Реализацию первого сценария и интерфейсы согласовать в T002 перед следующим TASK.
Критерии задач с кодом: поведение, ошибки/неполные данные, применимые проверки,
README изменённого модуля, воспроизводимый запуск и актуальная точка продолжения.
Для этого docs-only перехода кодовые рефакторинги и unit-прогоны не требуются.
