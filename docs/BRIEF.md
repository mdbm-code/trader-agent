# Назначение

Владелец хочет изучать рынок ценных бумаг в поисках возможных точек входа.
Разработка переносится на тот же сервер, где работает архитектор, — vds01.
На этой стадии используем существующий trader-agent и профиль FCIA 0.2.0 без APS.

## Подтверждено и предложено

Подтверждены цель исследования рынка, размещение рабочей копии на сервере и
выбор документации как у svc-comfyui. Имя репозитория сохраняется.
Предложение первого результата: UI списка наблюдения и карточки гипотез с графиком,
источниками/временем данных, основанием выделения и условием отмены гипотезы.
Это предложение для T002, ещё не утверждённый scope реализации.
Вид app также предлагается, но официального назначения FCIA нет.

## Что требуется решить в T002

- Рынок и инструменты: прежний код использует MOEX/T-Invest, новый выбор не подтверждён.
- Горизонт: внутридневной, дни/недели либо месяцы.
- Правила поиска кандидатов и критерии первого полезного результата.
- Источники данных, допустимая задержка/полнота и история; доступы выяснить без чтения секретов.
- Способ доступа к будущему UI и модель доступа; порт новой установки пока не назначен.
- Есть ли старая установка и данные для переноса; пока UNKNOWN.
- Нужна ли LLM и для какой операции; провайдер/модель не выбраны.

В этом документальном этапе нет допуска к брокеру, заявкам, установке зависимостей
или службам. Прежние планы торговли/биллинга/мультиарендности не становятся новыми задачами.
