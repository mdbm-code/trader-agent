# ADR 0002 — профиль FCIA 0.2.0 для существующего trader-agent

Дата: 25.11.2026. Статус: принято прямым поручением владельца для документации.

## Контекст

Владелец возобновляет проект как помощника исследования рынка; рабочая копия
перенесена на vds01. APS пока не поддерживает нужный ему удалённый сценарий.
Запрошена версия документов как в svc-comfyui. Проверено: это starter/profile 0.2.0,
source bccefddef1757728611b1fb101a8c857cd60fb34, а не APS starter 0.3.0.

## Решение

Сохранить репозиторий, код и имя trader-agent. Адаптировать общие документы, роли,
policy snapshots и TASK/Axx/Rxx; подготовить новый паспорт разработки без официальных
IDs. Состояние svc-comfyui и его product contracts/допуски не копировать.
Старый roadmap отделить; учебные документы и большая архитектура робота помечаются
историей, исходные байты доступны в базовом commit 081fef59927209c0baba201e3ea2dd584d3673f6.
Старое правило commit/push владельцем пока сохранить. Не внедрять .aps или _docs.

## Последствия

Новый исполнитель начинает с одного START и видит продуктовые пробелы в T002.
Сохраняются самостоятельная разработка без APS и будущая возможность отдельной миграции.
Ни вид app, ни конкретный UI, рынок и торговый горизонт этим ADR не утверждены.
Runtime и текущая работоспособность старой установки остаются вне этой сдачи.
