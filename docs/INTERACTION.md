# Подключение общего протокола

Источник: [принятая норма FCIA](https://github.com/mdbm-code/ai-ecosystem-architecture/blob/cf2f892750381e725c5b393e6128094c34fa5149/standards/AGENT-INTERACTION.md). Hash и квитанции — [LOCK](../policy/LOCK.json).
Подключение документации выполнено в этом стартере; рабочие инструменты совета не установлены.
Текущее назначение — ASSIGNMENTS.json; локальные задачи — docs/tasks/<Txxx>/TASK.md.
Реестр заседаний: NOT_CONFIGURED. Короткое CHAT0048 не разрешать угадыванием URL.

Перед участием проверять мандат, пакет/версию и роль; сохранять прежнюю работу и
незавершённые операции. Передача сообщения не равна исполнению. UNKNOWN сверять
по прежнему ID. Возврат к разработке разрешён без нового общего вопроса, если
предусмотрен действующим мандатом/сценарием. /goal не является обязательным транспортом.
Шаблон пакета и карточки содержится в каноническом документе и его офлайн-снимке.
