# Шаблоны

Копируй только нужный шаблон в docs/tasks или docs/adr. Шаблон не является выданным заданием. Общая карточка участия находится в норме AGENT-INTERACTION из policy/LOCK.json.

CHECKPOINT.md — краткая запись продолжения и проверки согласованности состояния.
Встраивать в текущие отчёты; отдельный файл на каждую реплику не требуется.

[CODE-STRUCTURE](CODE-STRUCTURE.md) — профиль языка, структуры, зависимостей и работы разработчика.
