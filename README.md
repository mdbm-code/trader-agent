# trader-agent

Торговый робот для Московской биржи на T-Invest API (Т-Банк). Node.js 24, сервер Ubuntu 24.04, пользователь `trader`.

## Быстрый старт

Развёртывание с нуля описано в [Sprint 01](docs/sprints/sprint-01-environment.md). Если окружение уже готово:

```bash
cp .env.example .env && chmod 600 .env   # вписать токен в редакторе, не в терминале
npm run smoke
```

## Документация

- [Архитектура](docs/architecture/ARCHITECTURE.md) — слои, модули, SOLID, DI и паттерны с аналогиями из 1С.
- [Дорожная карта](docs/ROADMAP.md) — все спринты: цели, результаты, что изучаем.

## Спринты

Каждый крупный этап завершается документом в `docs/sprints/` и git-тегом. Документ спринта одновременно служит инструкцией для воспроизведения результата с нуля.

| № | Документ | Тег | Итог |
|---|---|---|---|
| 01 | [Развёртывание окружения](docs/sprints/sprint-01-environment.md) | `sprint-01` | Сервер, доступ к T-Invest API, smoke-тест в песочнице |

**Правила оформления**

- Имя файла: `docs/sprints/sprint-NN-<тема>.md`, номер с ведущим нулём (`01`, `02`, …), чтобы файлы сортировались по порядку.
- Структура документа: итог → шаги воспроизведения с ожидаемым результатом → грабли → наблюдения → следующий спринт.
- Завершение спринта: коммит `docs: sprint NN — <тема>` и аннотированный тег `sprint-NN`. Посмотреть состояние проекта на конец спринта: `git checkout sprint-NN`.

## Безопасность

- Секреты хранятся только в `.env` с правами 600. В git попадает только `.env.example` с пустыми значениями.
- Робот и Claude Code работают под пользователем `trader` без sudo.
- Боевой full-access токен выпускается только на отдельный счёт робота.
