# trader-agent

Проект помощника для изучения рынка ценных бумаг и поиска возможных точек входа.
Это текущий замысел владельца; аналитический продукт пока не реализован.
Сохранён TypeScript-каркас прежнего торгового робота и история разработки.

- [Назначение и открытые вопросы](docs/BRIEF.md), [архитектура](docs/ARCHITECTURE.md).

- [Версия документации](docs/STRUCTURE-VERSION.md), [паспорт разработки](project.json).

На vds01 размещена только рабочая копия. Нет подтверждённого работающего UI,
потока котировок, аналитического движка или развёрнутой службы.
Скрипт scripts/smoke.mjs обращается к песочнице брокера и может создать счёт;
это не локальный тест и не старт приложения. Не запускать автоматически.

Применён профиль документации FCIA 0.2.0, как в svc-comfyui; APS не требуется.
Компонент не зарегистрирован в FCIA. Название репозитория сохранено; вид и
возможное переименование обсуждаются в T002. Исторический план торгового робота
доступен в [прежней дорожной карте](docs/ROADMAP-20260912.md).
